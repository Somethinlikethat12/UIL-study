# UIL Science Reference Sheet

A verified, concise formula and constants sheet will be built here as topics are studied. Every entry should include symbol definitions, units, and common rearrangements. Check values against reliable course or official references before using them in a test.

## Conventions
- Keep units attached to every measured quantity.
- Use dimensional analysis to check conversions and equations.
- Distinguish exact counts/conversions from measured values when applying significant figures.
- Record the conditions and assumptions under which each equation applies.
